# claude-freecad-mcp

Drive a running FreeCAD from Claude Code, in plain English. What it makes are
ordinary FreeCAD features, so you can open them afterwards and change the
numbers by hand. It reads what you have clicked in the 3D view, so you can
select a face and then talk about it.

- [Installing](INSTALL.md)
- [Tools](TOOLS.md)

LGPL 2.1 or later.
